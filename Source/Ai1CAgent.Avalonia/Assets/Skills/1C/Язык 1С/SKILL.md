# Язык 1С

## Назначение

Скилл описывает базовый синтаксис встроенного языка 1С (BSL) и помогает писать корректный код модулей: объявление переменных, процедуры и функции, ветвления, циклы, обработку исключений и директивы компиляции.

## Ключевые понятия

- Инструкция завершается символом `;`, регистр ключевых слов не важен, но код принято писать на русском.
- `Процедура` не возвращает значение, `Функция` возвращает через `Возврат`.
- Область видимости переменных: `Перем` в начале модуля, локальные переменные внутри методов.
- Директивы компиляции `&НаКлиенте`, `&НаСервере`, `&НаСервереБезКонтекста` задают, где исполняется метод.
- Комментарии начинаются с `//`.

## Как это работает

Платформа исполняет код построчно. Ключевые конструкции:

- Условие: `Если` / `ИначеЕсли` / `Иначе` / `КонецЕсли`.
- Циклы: `Для ... По ... Цикл`, `Для Каждого ... Из ... Цикл`, `Пока ... Цикл`.
- Исключения: `Попытка` / `Исключение` / `КонецПопытки`, сведения доступны через `ОписаниеОшибки()`.
- Операторы сравнения: `=`, `<>`, `<`, `>`, `<=`, `>=`; логические: `И`, `ИЛИ`, `НЕ`.
- Логическое «И» и «ИЛИ» вычисляются полностью, порядок скобок важен для читаемости.

## Пример кода

```bsl
// Возвращает скидку клиента с проверкой входных данных
Функция РассчитатьСкидку(СуммаЗаказа, ЭтоПостоянныйКлиент) Экспорт
    Перем Скидка;

    Если СуммаЗаказа = Неопределено ИЛИ СуммаЗаказа < 0 Тогда
        ВызватьИсключение "Некорректная сумма заказа";
    КонецЕсли;

    Если ЭтоПостоянныйКлиент Тогда
        Скидка = 10;
    ИначеЕсли СуммаЗаказа >= 100000 Тогда
        Скидка = 5;
    Иначе
        Скидка = 0;
    КонецЕсли;

    Возврат Скидка;
КонецФункции

// Перебирает коллекцию товаров и суммирует стоимость
Процедура ОбработатьТовары(Товары)
    Итог = 0;
    Для Каждого СтрокаТовара Из Товары Цикл
        Попытка
            Итог = Итог + СтрокаТовара.Количество * СтрокаТовара.Цена;
        Исключение
            // Пропускаем строку и продолжаем обработку
            Продолжить;
        КонецПопытки;
    КонецЦикла;
    Сообщить("Итог: " + Итог);
КонецПроцедуры
```

## Типичные ошибки

- Использование `=` вместо `=` в условии недопустимо: сравнение в 1С это `=`, присваивания внутри условия нет.
- Пропущен символ `;` в конце инструкции.
- Обращение к `ОписаниеОшибки()` вне блока `Исключение` даёт пустую строку.
- Путаница `Процедура` и `Функция`: функция без `Возврат` вернёт `Неопределено`.
- Забытые директивы компиляции приводят к ошибке «обращение к серверному методу на клиенте».
