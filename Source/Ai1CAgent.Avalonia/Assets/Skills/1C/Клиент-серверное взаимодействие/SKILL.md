# Клиент-серверное взаимодействие

## Назначение

Раздел описывает разделение кода формы на клиентский и серверный при помощи директив компиляции и правила обмена данными между клиентом и сервером. Скилл применяется при написании модулей управляемых форм и команд.

## Ключевые понятия

- **&НаКлиенте** — исполняется на машине пользователя, имеет доступ к элементам формы.
- **&НаСервере** — исполняется на сервере в контексте формы, доступны реквизиты и объект.
- **&НаСервереБезКонтекста** — серверный код без доступа к форме, принимает параметры.
- **Контекст формы** — реквизиты, объект и элементы, доступные на сервере.
- **Передача данных** — клиент вызывает серверный метод с параметрами.

## Как это работает

Каждая процедура модуля формы помечается директивой компиляции. Клиентский код отвечает за интерфейс: реакцию на действия пользователя, показ сообщений, открытие форм. Серверный код работает с данными: объектами, запросами, записью. Клиент не может напрямую читать реквизиты объекта на сервере, а сервер не может обращаться к элементам формы.

Для обмена клиент вызывает серверные методы с параметрами, а результаты возвращает через значение функции или через реквизиты формы. Серверные методы без контекста быстрее: в них нельзя обращаться к форме, но можно передать всё нужное параметрами.

## Пример

```bsl
&НаКлиенте
Процедура РассчитатьИтог(Команда)
    
    // Клиент готовит параметры и вызывает серверный метод
    Итог = РассчитатьИтогНаСервере(Объект.Организация, Объект.Дата);
    ПоказатьПредупреждение(, "Итог: " + Формат(Итог, "ЧДЦ=2"));
    
КонецПроцедуры

&НаСервере
Функция РассчитатьИтогНаСервере(Организация, ДатаДокумента)
    
    // Доступ к данным сервера в контексте формы
    Запрос = Новый Запрос;
    Запрос.Текст =
        "ВЫБРАТЬ СУММА(Продажи.Сумма) КАК Итог
        |ИЗ РегистрНакопления.Продажи КАК Продажи
        |ГДЕ Продажи.Организация = &Организация
        |   И Продажи.Период <= &Дата";
    Запрос.УстановитьПараметр("Организация", Организация);
    Запрос.УстановитьПараметр("Дата", ДатаДокумента);
    
    Выборка = Запрос.Выполнить().Выбрать();
    Если Выборка.Следующий() Тогда
        Возврат Выборка.Итог;
    КонецЕсли;
    
    Возврат 0;
    
КонецФункции

&НаСервереБезКонтекста
Функция КурсВалюты(Код)
    
    Запрос = Новый Запрос("ВЫБРАТЬ ПЕРВЫЕ 1 Курс ИЗ РегистрСведений.КурсыВалют "
        + "ГДЕ Код = &Код УПОРЯДОЧИТЬ ПО Период УБЫВ");
    Запрос.УстановитьПараметр("Код", Код);
    Возврат Запрос.Выполнить().Выбрать().Курс;
    
КонецФункции
```

## Типичные ошибки

- Обращение к `Элементы` из серверного кода без контекста формы.
- Передача тяжёлых данных клиенту, когда достаточно агрегата.
- Межсерверный вызов: `&НаСервере` вызывает процедуру другого серверного контекста.
- Длительная серверная операция без оповещения клиента.
- Использование модальных вызовов в серверном коде.
