# Реквизиты и обработчики формы

## Назначение

Раздел описывает реквизиты управляемой формы и её ключевые обработчики жизненного цикла: `ПриСозданииНаСервере`, `ПриОткрытии`, обработчик заполнения и реакцию на изменение значения. Скилл применяется при инициализации формы и заполнении данных.

## Ключевые понятия

- **Реквизит формы** — типизированное данное формы, доступное её элементам.
- **Основной реквизит** — реквизит с ссылкой на объект, задающий контекст формы.
- **ПриСозданииНаСервере** — серверная инициализация формы до показа.
- **ПриОткрытии** — завершающее событие после открытия формы.
- **Заполнение** — заполнение объекта данными по значению заполнения.
- **ПриИзменении** — реакция на изменение значения реквизита пользователем.

## Как это работает

При открытии формы платформа создаёт реквизиты и вызывает `ПриСозданииНаСервере` — здесь выполняют настройку формы, чтение параметров и предварительное заполнение. Затем на клиенте наступает `ПриОткрытии`. Обработчик `Заполнение` вызывается при создании объекта по значению заполнения и получает ссылку-источник. Обработчики вида `ПриИзменении` выполняются на клиенте и могут вызвать серверные методы для пересчёта.

Параметры формы объявляются в свойстве «Параметры» и доступны в `ПриСозданииНаСервере`. Если параметр передан, его значение нужно перенести в реквизиты формы.

## Пример

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    
    Если Параметры.Свойство("ЗначениеЗаполнения") 
        И НЕ Параметры.ЗначениеЗаполнения.Пустая() Тогда
        ЗаполнитьПоЗначениюЗаполнения(Параметры.ЗначениеЗаполнения);
    КонецЕсли;
    
    Если Параметры.Свойство("Основание") Тогда
        ЗаполнитьПоОснованию(Параметры.Основание);
    КонецЕсли;
    
КонецПроцедуры

&НаКлиенте
Процедура ПриОткрытии(Отказ)
    ПодключитьОбработчикОжидания("ОбновитьСтатус", 5, Истина);
КонецПроцедуры

&НаСервере
Процедура ЗаполнитьПоЗначениюЗаполнения(ДокументОснование)
    ЗаполнитьЗначенияСвойств(Объект, ДокументОснование);
    Объект.Дата = ТекущаяДатаСеанса();
    Для Каждого СтрокаТЧ Из ДокументОснование.Товары Цикл
        НоваяСтрока = Объект.Товары.Добавить();
        ЗаполнитьЗначенияСвойств(НоваяСтрока, СтрокаТЧ);
    КонецЦикла;
КонецПроцедуры

&НаКлиенте
Процедура ЦенаПриИзменении(Элемент)
    ПересчитатьСуммыНаСервере();
КонецПроцедуры

&НаСервере
Процедура ПересчитатьСуммыНаСервере()
    Для Каждого СтрокаТЧ Из Объект.Товары Цикл
        СтрокаТЧ.Сумма = СтрокаТЧ.Количество * СтрокаТЧ.Цена;
    КонецЦикла;
КонецПроцедуры
```

## Типичные ошибки

- Изменение данных объекта на клиенте вместо серверного обработчика.
- Параметр формы не перенесён в реквизит, из-за чего теряется при переоткрытии.
- Тяжёлые вычисления прямо в `ПриИзменении` на клиенте без серверного вызова.
- Ожидание обращения к реквизиту объекта без его предварительного чтения.
- Двойное заполнение: и в `ПриСозданииНаСервере`, и в `Заполнение`.
