# Модули 1С

## Назначение

Скилл объясняет, какие бывают модули в 1С, где они исполняются и как с помощью директив компиляции разделять клиентский и серверный код.

## Ключевые понятия

- Модуль приложения, модуль сеанса, внешнего соединения.
- Общие модули — общий код, вызываемый из разных мест.
- Модуль объекта, модуль менеджера, модуль набора записей.
- Модуль формы, модуль команды, модуль отчёта.
- Директивы компиляции: `&НаКлиенте`, `&НаСервере`, `&НаСервереБезКонтекста`, `&НаКлиентеНаСервереБезКонтекста`.
- Свойства общего модуля: «Сервер», «Клиент», «Внешнее соединение», «Привилегированный».

## Как это работает

- Код формы исполняется на клиенте и на сервере; директива определяет место выполнения метода.
- `&НаСервереБезКонтекста` не имеет доступа к данным формы и работает только с переданными аргументами.
- `&НаСервере` видит реквизиты формы, но требует передачи формы на сервер — дороже.
- Общий модуль доступен только с той стороны, для которой включён в свойствах.
- Клиентский код не имеет прямого доступа к базе; данные получают через серверные вызовы.

## Пример кода

```bsl
// Общий модуль с серверными методами
// Свойства модуля: Сервер = Истина, ВызовСервера = Истина

Функция ЦенаТовара(Товар) Экспорт
    // Выполняется на сервере, есть доступ к базе
    Запрос = Новый Запрос;
    Запрос.Текст =
        "ВЫБРАТЬ Цены.Цена
        |ИЗ РегистрСведений.ЦеныНоменклатуры КАК Цены
        |ГДЕ Цены.Номенклатура = &Номенклатура";
    Запрос.УстановитьПараметр("Номенклатура", Товар);
    Выборка = Запрос.Выполнить().Выбрать();
    Если Выборка.Следующий() Тогда
        Возврат Выборка.Цена;
    КонецЕсли;
    Возврат 0;
КонецФункции

// Модуль формы обработки
&НаКлиенте
Процедура ПриОткрытии(Отказ)
    ОбновитьЦены();
КонецПроцедуры

&НаКлиенте
Процедура ОбновитьЦены()
    Для Каждого Строка Из Объект.Товары Цикл
        // Клиент вызывает серверную функцию общего модуля
        Строка.Цена = ОбщийМодульЦен.ЦенаТовара(Строка.Товар);
    КонецЦикла;
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПолучитьНаименование(Ссылка)
    Возврат СокрЛП(Ссылка.Наименование);
КонецФункции
```

## Типичные ошибки

- Вызов серверной процедуры из клиентского контекста без директивы — ошибка компиляции.
- Обращение к реквизитам формы в `&НаСервереБезКонтекста` — недоступно.
- Диалоги (`Вопрос`, `Предупреждение`) вызываются только на клиенте.
- Тяжёлые операции в `&НаСервере` формы вместо вынесения в общий модуль.
- Обращение к базе из клиентского кода напрямую.
