# Планы счетов

## Назначение

План счетов задаёт перечень синтетических счетов и их настройки для регистра бухгалтерии: вид счёта, состав субконто, признаки учёта. Он определяет, как ведутся проводки и какая аналитика доступна на каждом счёте. План счетов — обязательный источник счетов для регистра бухгалтерии.

## Ключевые понятия

- Счёт — элемент плана с кодом, наименованием и настройками.
- Вид счёта: активный, пассивный, активно-пассивный. Влияет на знак и расчёт остатков.
- Виды субконто — набор аналитических разрезов счёта (Контрагент, Номенклатура, Статья).
- Максимальное количество субконто — сколько аналитик допускает счёт.
- Признаки учёта — по подразделению, по количеству, по валюте.
- Забалансовый счёт — учёт вне баланса, обороты не влияют на баланс.
- Предопределённые счета — заданы в конфигурации и на них опирается логика.
- Субсчета — иерархия кодов (60, 60.01, 60.02).

## Как это работает

Счёт создаётся в плане вручную или при конфигурировании. При привязке к регистру бухгалтерии платформа использует измерения `СчетДт` и `СчетКт`. Настройки счёта определяют, какие субконто допустимы в проводках. Забалансовые счета помечаются признаком и ведутся отдельно; при двойной записи забалансовые проводки не создают корреспонденцию с основными счетами.

Код счёта строится по иерархии: старший счёт и субсчета. Обращение к счёту в коде обычно идёт через `НайтиПоКоду`, `НайтиПоНаименованию` или предопределённый счёт `ПланыСчетов.Хозрасчетный.РасчетыСПоставщиками`.

## Пример

Создание счёта и субсчёта:

```bsl
Родитель = ПланыСчетов.Хозрасчетный.НайтиПоКоду("90");
Счет = ПланыСчетов.Хозрасчетный.СоздатьЭлемент();
Счет.Код = "90.01";
Счет.Наименование = "Выручка";
Счет.Родитель = Родитель;
Счет.Вид = ВидСчета.АктивноПассивный;
Счет.МаксКоличествоСубконто = 1;
Счет.ВидыСубконто.Добавить(ПланыВидовХарактеристик.ВидыСубконто.НайтиПоНаименованию("Номенклатура"));
Счет.Записать();
```

Использование предопределённого счёта при проведении:

```bsl
Движение.СчетДт = ПланыСчетов.Хозрасчетный.РасчетыСПокупателями;
Движение.СчетКт = ПланыСчетов.Хозрасчетный.Выручка;
```

## Типичные ошибки

- Не задают виды субконто счёта, а потом пытаются записать аналитику — платформа отклоняет.
- Создают забалансовый счёт без признака забалансовости, и он попадает в баланс.
- Опираются на произвольный код счёта вместо предопределённого — код могут изменить.
- Путают вид счёта: для активно-пассивного неверно трактуют развёрнутый остаток.
- Заводят субсчёт без родителя, нарушая иерархию кодов.
- Меняют настройки счёта после того, как по нему уже есть проводки.
