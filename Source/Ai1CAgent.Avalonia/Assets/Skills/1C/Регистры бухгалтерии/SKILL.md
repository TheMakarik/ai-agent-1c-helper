# Регистры бухгалтерии

## Назначение

Регистр бухгалтерии хранит проводки — записи о хозяйственных операциях с корреспонденцией счетов. Он реализует двойную запись: каждая проводка содержит дебет и кредит. На его основе строится бухгалтерская отчётность, оборотно-сальдовые ведомости и анализ по субконто.

## Ключевые понятия

- План счетов — источник счетов регистра (платформа хранит ссылку на счёт в измерении `СчетДт`/`СчетКт` или в `Счет`).
- Проводка — строка движения: период, документ, дебет, кредит, сумма.
- Корреспонденция — указание пар «счёт дебета — счёт кредита».
- Субконто — разрез аналитики на счёте (Контрагент, Номенклатура, Сотрудник). Хранится в таблице субконто.
- Виды субконто — набор аналитик, приписанный счёту (максимальное количество субконто).
- Регистр бухгалтерии с поддержкой корреспонденции или без неё (только один счёт на строку).
- Виртуальные таблицы: `Остатки`, `Обороты`, `ОстаткиИОбороты`, `ДвиженияССубконто`, `ОборотыДтКт`.

## Как это работает

Счёт выбирается из плана счетов, привязанного к регистру. При заполнении движения задаются счёт дебета, счёт кредита, сумма и субконто каждого счёта. Субконто хранится в отдельной таблице набора записей (`Движения.Регистр.Субконто` или через свойства `СубконтоДт`, `СубконтоКт`). При записи набора платформа синхронизирует основную таблицу и таблицу субконто.

Остатки и обороты по счетам рассчитываются виртуальными таблицами с отбором по счёту, субконто и периоду. Для баланса одного счёта важно учитывать, что дебет и кредит — это одни и те же ресурсы (`Сумма`), а направление задаётся счётом.

## Пример

Формирование проводки при проведении документа:

```bsl
Процедура ОбработкаПроведения(Отказ, РежимПроведения)
    Движения.Хозрасчетный.Записывать = Истина;
    Движения.Хозрасчетный.Очистить();
    Для Каждого СтрокаТЧ Из Услуги Цикл
        Проводка = Движения.Хозрасчетный.Добавить();
        Проводка.Период = Дата;
        Проводка.СчетДт = ПланыСчетов.Хозрасчетный.НайтиПоКоду("26");
        Проводка.СчетКт = ПланыСчетов.Хозрасчетный.НайтиПоКоду("60.01");
        Проводка.Сумма = СтрокаТЧ.Сумма;
        Проводка.СубконтоКт.Добавить(СтрокаТЧ.Контрагент);
    КонецЦикла;
КонецПроцедуры
```

Обороты и остатки по счёту с субконто:

```bsl
ВЫБРАТЬ
    Остатки.Субконто1 КАК Контрагент,
    Остатки.СуммаОстаток КАК ДолгКонец
ИЗ
    РегистрБухгалтерии.Хозрасчетный.Остатки(
        &МоментВремени,
        Счет = &Счет,
        , Контрагент = &Контрагент) КАК Остатки
```

Отчёт по корреспонденции за период:

```bsl
ВЫБРАТЬ
    Обороты.СчетДт КАК СчетДт,
    Обороты.СчетКт КАК СчетКт,
    СУММА(Обороты.СуммаОборот) КАК Сумма
ИЗ
    РегистрБухгалтерии.Хозрасчетный.Обороты(
        &Начало, &Конец, Регистратор) КАК Обороты
СГРУППИРОВАТЬ ПО
    Обороты.СчетДт, Обороты.СчетКт
```

## Типичные ошибки

- Путают ресурс и субконто: субконто хранится отдельной таблицей, его нельзя записать как обычный ресурс.
- Записывают субконто, не проверив вид субконто счёта, — платформа отклоняет запись.
- Считают обороты суммой проводок вручную и теряют разворот по субконто.
- Для счёта с корреспонденцией заполняют только один счёт вместо дебета и кредита.
- Не учитывают, что активность счёта и забалансовость влияют на расчёт остатков.
- Обращаются к субконто по индексу, не зная настройку счёта, — не тот разрез.
