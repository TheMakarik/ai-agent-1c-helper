# Регистры накопления

## Назначение

Регистр накопления хранит числовые показатели в разрезе набора измерений и служит для количественного учёта: товаров, взаиморасчётов, продаж, денежных средств. Он накапливает движения (приход и расход) и позволяет получать итоги — остатки и обороты — без обхода документов.

## Ключевые понятия

- Измерение — разрез учёта (Номенклатура, Склад, Контрагент). По измерениям группируют и отбирают.
- Ресурс — числовой показатель (Количество, Сумма), который суммируется.
- Реквизит — дополнительное поле, не влияющее на итоги (Цена, Валюта, Комментарий).
- Вид регистра — «Остатки» или «Обороты». Для вида «Остатки» платформа рассчитывает остаток как приход минус расход.
- Движение — одна запись регистра, создаваемая документом при проведении.
- Структурная единица — таблица движений (РегистрНакопления.Имя). Виртуальные таблицы дают остатки и обороты.
- Виртуальные таблицы: `Остатки`, `Обороты`, `ОстаткиИОбороты`, `ОборотыДтКт` (для вида «Обороты»).

## Как это работает

Документ при проведении формирует набор записей (`РегистрНакопленияМенеджер.СоздатьНаборЗаписей` или через свойство `Движения`). В модуле объекта в `ОбработкаПроведения` набор очищается, заполняется строками движений и записывается в режиме `РежимЗаписиДвижения.Онлайн`. Платформа при записи автоматически поддерживает актуальность итогов по измерениям.

Чтение данных выполняется запросом. Прямое обращение к таблице движений даёт все записи; виртуальные таблицы остатков и оборотов рассчитывают итоги на указанный момент (`&Период`) с отбором по измерениям. Актуальные остатки выгоднее получать через виртуальную таблицу с параметром периода, а не агрегировать движения вручную.

## Пример

Запись движений при проведении документа:

```bsl
Процедура ОбработкаПроведения(Отказ, РежимПроведения)
    Движения.ТоварыНаСкладах.Записывать = Истина;
    Движения.ТоварыНаСкладах.Очистить();
    Для Каждого СтрокаТЧ Из Товары Цикл
        Движение = Движения.ТоварыНаСкладах.Добавить();
        Движение.Период = Дата;
        Движение.ВидДвижения = ВидДвиженияНакопления.Расход;
        Движение.Номенклатура = СтрокаТЧ.Номенклатура;
        Движение.Склад = Склад;
        Движение.Количество = СтрокаТЧ.Количество;
    КонецЦикла;
КонецПроцедуры
```

Получение остатков запросом:

```bsl
ВЫБРАТЬ
    Остатки.Номенклатура КАК Номенклатура,
    Остатки.КоличествоОстаток КАК КоличествоОстаток
ИЗ
    РегистрНакопления.ТоварыНаСкладах.Остатки(
        &МоментВремени,
        Склад = &Склад) КАК Остатки
УПОРЯДОЧИТЬ ПО
    Остатки.Номенклатура
```

Обороты за период по измерению:

```bsl
ВЫБРАТЬ
    Обороты.Номенклатура КАК Номенклатура,
    Обороты.КоличествоПриход КАК Приход,
    Обороты.КоличествоРасход КАК Расход,
    Обороты.КоличествоОборот КАК Оборот
ИЗ
    РегистрНакопления.ТоварыНаСкладах.Обороты(
        &НачалоПериода, &КонецПериода, , Склад = &Склад) КАК Обороты
```

## Типичные ошибки

- Забыли установить `Записывать = Истина` — движения не записываются, проведение «пустое».
- Не очистили набор перед повторным заполнением — дубли движений.
- Пытаются получить остаток суммированием движений вручную — теряют данные до периода и работают медленнее виртуальной таблицы.
- Путают реквизит и ресурс: реквизит не суммируется и не становится показателем итога.
- Измерению не задан порядок или свойство «Ведущее», а на него опираются при отборе — неожиданные группировки.
- Запись движений в обход проведения документа — рассинхронизация регистра и документов.
