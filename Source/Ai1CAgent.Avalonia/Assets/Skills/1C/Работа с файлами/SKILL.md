# Работа с файлами

## Назначение

Раздел описывает работу с файлами и двоичными данными в 1С: чтение и запись файлов, помещение файлов во временное хранилище, работу с картинками и получение данных на сервере. Скилл применяется при импорте, экспорте и хранении вложений.

## Ключевые понятия

- **ДвоичныеДанные** — объект для хранения произвольного набора байт.
- **Адрес во временном хранилище** — строка-ссылка на данные, передаваемая между клиентом и сервером.
- **ПоместитьФайл** — помещение выбранного файла во временное хранилище.
- **ЧтениеДанных** — чтение из файла или потока по частям.
- **Картинка** — объект для изображений, получаемый из двоичных данных.
- **ПотокВПамяти** — буфер в памяти для чтения и записи.

## Как это работает

На клиенте файл выбирается диалогом и помещается во временное хранилище; клиент получает адрес, который передаётся на сервер. На сервере по адресу получают двоичные данные через `ПолучитьИзВременногоХранилища`. Для чтения больших файлов по частям используется объект `ЧтениеДанных` с методами `Прочитать`.

Из двоичных данных можно получить картинку через конструктор `Новый Картинка(ДвоичныеДанные)`. Для передачи данных обратно на клиент используют `ПоместитьВоВременноеХранилище`. Запись в файл на сервере выполняется методом `Записать` или `НачатьЗапись`.

## Пример

```bsl
&НаКлиенте
Асинх Процедура ЗагрузитьКартинку(Команда)
    
    Описание = Новый ОписаниеОповещения("ПослеВыбораКартинки", ЭтотОбъект);
    Параметры = Новый Структура("Фильтр", "Изображения (*.png)|*.png|(*.*)|*.*");
    НачатьПомещениеФайла(Описание, Ложь, , УникальныйИдентификатор, Параметры);
    
КонецПроцедуры

&НаКлиенте
Процедура ПослеВыбораКартинки(Результат, ДополнительныеПараметры) Экспорт
    
    Если Результат = Неопределено Тогда
        Возврат;
    КонецЕсли;
    
    // Результат содержит адрес во временном хранилище
    ПрисоединитьКартинкуНаСервере(Результат.Адрес, Результат.ПолноеИмя);
    
КонецПроцедуры

&НаСервере
Процедура ПрисоединитьКартинкуНаСервере(Адрес, ИмяФайла)
    
    ДвоичныеДанные = ПолучитьИзВременногоХранилища(Адрес);
    
    // Чтение по частям для больших данных
    Чтение = Новый ЧтениеДанных(ДвоичныеДанные);
    ПервыеБайты = Чтение.Прочитать(16, КодировкаТекста.ANSI);
    
    // Получение картинки и сохранение вложение
    Картинка = Новый Картинка(ДвоичныеДанные);
    Элементы.ПолеКартинки.РазмерКартинки = РазмерКартинкиКартинок.Растянуть;
    Элементы.ПолеКартинки.Картинка = Новый Картинка(ДвоичныеДанные, Истина);
    
    НовыйАдрес = ПоместитьВоВременноеХранилище(ДвоичныеДанные);
    
КонецПроцедуры
```

## Типичные ошибки

- Попытка прочитать файл на клиенте без помещения во временное хранилище.
- Не освобождённый адрес во временном хранилище при частой загрузке.
- Чтение всего файла целиком там, где нужно читать потоком.
- Построение картинки из данных неподдерживаемого формата.
- Потеря адреса при передаче между серверными вызовами без явной передачи параметром.
