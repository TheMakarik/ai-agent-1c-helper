# Группировки и итоги

## Назначение

Группировка сворачивает множество строк в одну на группу и позволяет считать агрегаты: суммы, количества, минимумы и максимумы. Предложение `ИТОГИ` добавляет в результат иерархические итоги по указанным полям. Группировки — основа сводных отчётов и печатных форм с подведением итогов.

## Ключевые понятия

- `СГРУППИРОВАТЬ ПО` — список полей, по которым объединяются строки.
- Агрегатные функции: `СУММА`, `КОЛИЧЕСТВО`, `МИНИМУМ`, `МАКСИМУМ`, `СРЕДНЕЕ`.
- `КОЛИЧЕСТВО(*)` — число строк, `КОЛИЧЕСТВО(Поле)` — число непустых значений.
- `ИМЕЮЩИЕ` — отбор уже сгруппированных строк, может ссылаться на агрегаты.
- `ИТОГИ` — итоговые строки по заданным полям, добавляются к плоской выборке.
- `ОБЩИЕ` в `ИТОГИ` — добавить общий итог без указания поля.
- `ТОЛЬКО ИЕРАРХИЯ` / ключевое слово у измерений — разворот по иерархии справочника.

## Как это работает

Сначала `ГДЕ` отбирает исходные строки, затем `СГРУППИРОВАТЬ ПО` объединяет их, после чего `ИМЕЮЩИЕ` фильтрует группы. Все поля выборки, не входящие в агрегат, обязаны быть в группировке. `ИТОГИ` не заменяют группировку, а добавляют к результату уровни итогов: при обходе выборки строки итогов появляются в заданных точках.

При работе с `ИТОГИ` результат содержит колонки-измерения (`Менеджер`, `Товар`) и агрегатные колонки. Для вывода только детальных строк отключают показ итогов, а для отчёта с деревом — включают. `ИМЕЮЩИЕ` часто используется для «продано больше N» или «остаток отрицательный».

## Пример

Группировка с агрегатами:

```bsl
ВЫБРАТЬ
    Продажи.Менеджер КАК Менеджер,
    Продажи.Номенклатура КАК Товар,
    СУММА(Продажи.Количество) КАК Количество,
    СУММА(Продажи.Сумма) КАК Сумма
ИЗ
    Документ.ПродажаТоваров.Товары КАК Продажи
ГДЕ
    Продажи.Ссылка.Проведен
СГРУППИРОВАТЬ ПО
    Продажи.Менеджер,
    Продажи.Номенклатура
```

Отбор по агрегату через `ИМЕЮЩИЕ`:

```bsl
СГРУППИРОВАТЬ ПО
    Продажи.Менеджер
ИМЕЮЩИЕ
    СУММА(Продажи.Сумма) > 100000
```

Итоги по менеджеру и товару:

```bsl
ИТОГИ
    СУММА(Количество),
    СУММА(Сумма)
ПО
    ОБЩИЕ,
    Менеджер,
    Товар
```

## Типичные ошибки

- Поле выборки не включено в `СГРУППИРОВАТЬ ПО` — ошибка неагрегатного поля.
- Условие по агрегату пишут в `ГДЕ` — ошибка, нужно `ИМЕЮЩИЕ`.
- Ждут детальных строк при использовании `ИТОГИ` и получают строки итогов вперемешку с детальными.
- `КОЛИЧЕСТВО(*)` и `КОЛИЧЕСТВО(Поле)` путают: второе игнорирует `NULL`.
- Группируют по полю с высокой кардинальностью без необходимости — большой результат.
- Отбор до группировки и после перепутаны, из-за чего итог неверный.
