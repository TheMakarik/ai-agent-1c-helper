# Настройки СКД

## Назначение

Раздел описывает работу с системой компоновки данных (СКД) в отчётах на 1С: как описывать наборы данных, ресурсы, параметры, вычисляемые поля, варианты и пользовательские настройки. Скилл нужен при разработке и правке схемы компоновки данных отчёта.

## Ключевые понятия

- **Набор данных** — источник строк отчёта: запрос, таблица, объединение.
- **Поле** — колонка набора данных, доступная для вывода и настроек.
- **Вычисляемое поле** — выражение на языке СКД, рассчитываемое на этапе компоновки.
- **Ресурс** — агрегируемое поле с заданной функцией итога (Сумма, Количество).
- **Параметр** — значение, подставляемое в набор данных и в выражения.
- **Вариант** — сохранённый набор настроек (выбранные поля, группировки, отборы).
- **Пользовательские настройки** — элементы, доступные конечному пользователю в интерфейсе.

## Как это работает

Схема компоновки описывается декларативно. На этапе выполнения платформа строит запрос по выбранным полям и условиям, применяет вычисляемые поля и агрегирует ресурсы по группировкам. Параметры подставляются в текст набора данных и в вычисляемые поля. Варианты и пользовательские настройки меняют итоговую компоновку без изменения кода.

Ресурсы задаются с функцией итога. Вычисляемые поля не попадают в SQL-запрос напрямую: они считаются платформой над результатом, поэтому могут использовать функции СКД (например, `ВычислитьВыражение`) и ссылаться на другие поля.

## Типичные ошибки

- Вычисляемое поле использует агрегатную функцию на уровне генерации SQL — платформа не может свернуть группировку.
- Ресурс добавляется без указания функции итога, из-за чего итог берётся неверно.
- Параметр СКД не совпадает по имени с параметром запроса — подстановка не происходит.
- Изменение пользовательских настроек без `Инициализировать` приводит к потере варианта.
- Вычисляемое поле обращается к полю, исключённому из вывода, и получает NULL.
