# Макеты

## Назначение

Раздел описывает макеты объектов метаданных: табличные документы, текстовые макеты, их области и параметры, а также программный вывод и заполнение областей. Скилл нужен при печати документов, построении форм и формировании выходных файлов.

## Ключевые понятия

- **Табличный документ** — основной макет вывода: ячейки, строки, колонки, области.
- **Область** — именованная часть макета, задаваемая в конструкторе.
- **Параметр области** — именованное значение, подставляемое перед выводом.
- **ОбластьМакетаСтрока** — тип области для вывода в цикле.
- **ОбластьМакетаКолонтитул** — область верхнего/нижнего колонтитула.
- **Текстовый документ** — макет со свободным текстом и замещаемыми параметрами.

## Как это работает

Макет хранится в объекте метаданных и получается методом `ПолучитьМакет`. Область извлекается по имени через `ПолучитьОбласть`. Параметры области заполняются перед выводом: имя параметра указывается в ячейке в квадратных скобках, а значение присваивается свойству `Параметры`. Вывод области в табличный документ выполняется методом `Вывести`.

Для вывода списка строк область выводится в цикле; для итогов используется отдельная область. Табличный документ можно показать на форме или сохранить в файл через `Записать`.

## Пример

```bsl
&НаСервере
Функция СформироватьПечатнуюФорму(Ссылка)
    
    Документ = Ссылка.ПолучитьОбъект();
    ТабДок = Новый ТабличныйДокумент;
    
    // Шапка
    Шапка = ПолучитьМакет("Печать").ПолучитьОбласть("Шапка");
    Шапка.Параметры.Номер = Документ.Номер;
    Шапка.Параметры.Дата = Формат(Документ.Дата, "ДЛФ=DD");
    Шапка.Параметры.Организация = Документ.Организация;
    ТабДок.Вывести(Шапка);
    
    // Строки табличной части
    ОбластьСтрока = ПолучитьМакет("Печать").ПолучитьОбласть("Строка");
    Для Каждого СтрокаТЧ Из Документ.Товары Цикл
        ОбластьСтрока.Параметры.Номенклатура = СтрокаТЧ.Номенклатура;
        ОбластьСтрока.Параметры.Количество = СтрокаТЧ.Количество;
        ОбластьСтрока.Параметры.Сумма = СтрокаТЧ.Сумма;
        ТабДок.Вывести(ОбластьСтрока);
    КонецЦикла;
    
    // Итоги
    Итого = ПолучитьМакет("Печать").ПолучитьОбласть("Итого");
    Итого.Параметры.Всего = Документ.Товары.Итог("Сумма");
    ТабДок.Вывести(Итого);
    
    ТабДок.ОтображатьСетку = Ложь;
    Возврат ТабДок;
    
КонецФункции
```

## Типичные ошибки

- Параметр области не объявлен в макете, но присваивается в коде — значение теряется.
- Область получают с неверным именем и уровнем вложенности.
- Вывод области в цикле без сброса параметров переносит значения прошлой строки.
- Забыт вызов `Вывести`, в результате документ пуст.
- Использование строки вместо области при выводе.
