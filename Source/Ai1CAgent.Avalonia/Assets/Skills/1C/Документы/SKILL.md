# Документы

## Назначение

Скилл описывает объект метаданных «Документ»: регистрацию хозяйственных операций во времени, реквизиты, табличные части, проведение и формирование движений.

## Ключевые понятия

- `ДокументСсылка.Имя`, `ДокументОбъект.Имя` — ссылка и объект документа.
- Реквизиты шапки, табличные части (строки), формы документа и списка.
- Момент времени (дата и номер), нумератор, журналы документов.
- Проведение: обработчик `ОбработкаПроведения` в модуле объекта.
- Движения по регистрам, `Движения` и наборы записей.
- Оперативное и неоперативное проведение.

## Как это работает

- Документ создают через `СоздатьДокумент()`, заполняют шапку и табличные части, затем `Записать()`.
- Проведение запускается методом `Записать(РежимЗаписиДокумента.Проведение)`.
- В `ОбработкаПроведения` сначала очищают движения, затем формируют и записывают наборы записей.
- `Ссылка.Проведён` и `Ссылка.ПометкаУдаления` отражают состояние документа.
- Дата документа определяет период попадания движений в отчёты.

## Пример кода

```bsl
// Формирует документ расхода товаров и проводит его
Функция СоздатьРасходную(Дата, Склад, Товары) Экспорт
    Документ = Документы.РасходнаяНакладная.СоздатьДокумент();
    Документ.Дата = Дата;
    Документ.Склад = Склад;

    Для Каждого ТоварИзСписка Из Товары Цикл
        НоваяСтрока = Документ.Товары.Добавить();
        НоваяСтрока.Номенклатура = ТоварИзСписка.Номенклатура;
        НоваяСтрока.Количество = ТоварИзСписка.Количество;
        НоваяСтрока.Цена = ТоварИзСписка.Цена;
    КонецЦикла;

    Документ.Записать(РежимЗаписиДокумента.Проведение);
    Возврат Документ.Ссылка;
КонецФункции

// Обработчик в модуле объекта документа — движения по регистру накопления
Процедура ОбработкаПроведения(Отказ, РежимПроведения)
    // Сначала очищаем ранее сформированные движения
    Движения.ТоварыНаСкладах.Записывать = Истина;
    Движения.ТоварыНаСкладах.Очистить();

    Для Каждого СтрокаТовары Из Товары Цикл
        Движение = Движения.ТоварыНаСкладах.Добавить();
        Движение.ВидДвижения = ВидДвиженияНакопления.Расход;
        Движение.Период = Дата;
        Движение.Склад = Склад;
        Движение.Номенклатура = СтрокаТовары.Номенклатура;
        Движение.Количество = СтрокаТовары.Количество;
    КонецЦикла;
КонецПроцедуры
```

## Типичные ошибки

- Вызов `Записать(РежимЗаписиДокумента.Проведение)` без заполненного обработчика проведения — движения не формируются.
- Забытая очистка движений приводит к дублированию записей при повторном проведении.
- Изменение реквизитов через ссылку вместо объекта.
- Использование `ТекущаяДата()` вместо даты документа для периода движений.
- Отсутствие проверки заполненности табличной части перед проведением.
