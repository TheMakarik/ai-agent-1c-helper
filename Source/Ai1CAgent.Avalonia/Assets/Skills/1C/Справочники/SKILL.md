# Справочники

## Назначение

Скилл описывает объект метаданных «Справочник»: хранение условно-постоянной информации, реквизиты, табличные части, формы и работу с элементами из кода.

## Ключевые понятия

- `СправочникСсылка.Имя` — ссылка на элемент справочника.
- `СправочникОбъект.Имя` — объект для чтения и записи.
- Реквизиты, табличные части, формы (элемента и списка), команды.
- Предопределённые элементы — задаются в конфигураторе, неизменяемы пользователем.
- Иерархия, группы, владельцы, подчинение, нумератор.
- `СоздатьЭлемент()`, `НайтиПоКоду()`, `НайтиПоНаименованию()`, `ПустаяСсылка()`.

## Как это работает

- Ссылка (`СправочникСсылка`) — уникальный идентификатор; из неё получают реквизиты через точку.
- Для изменения элемента его получают как объект: `Ссылка.ПолучитьОбъект()`.
- Поиск без точной ссылки выполняют методом `НайтиПоНаименованию` с флагом поиска в группах.
- Предопределённые элементы доступны как `Справочники.Валюты.Рубль`.
- Заполненность ссылки проверяют `ЗначениеЗаполнено` или сравнением с `ПустаяСсылка()`.

## Пример кода

```bsl
// Создаёт или находит контрагента по ИНН
Функция ПолучитьКонтрагента(ИНН, Наименование) Экспорт
    Если ПустаяСтрока(ИНН) Тогда
        ВызватьИсключение "Не указан ИНН";
    КонецЕсли;

    Существующий = Справочники.Контрагенты.НайтиПоРеквизиту("ИНН", ИНН);
    Если ЗначениеЗаполнено(Существующий) Тогда
        Возврат Существующий;
    КонецЕсли;

    Объект = Справочники.Контрагенты.СоздатьЭлемент();
    Объект.Наименование = Наименование;
    Объект.ИНН = ИНН;
    Объект.Записать();
    Возврат Объект.Ссылка;
КонецФункции

// Демонстрация чтения реквизитов и работы с предопределёнными элементами
Процедура ВывестиИнформацию(Ссылка)
    Если НЕ ЗначениеЗаполнено(Ссылка) Тогда
        Сообщить("Контрагент не выбран");
        Возврат;
    КонецЕсли;

    // Чтение реквизитов через ссылку
    Сообщить("Наименование: " + Ссылка.Наименование);
    Сообщить("ИНН: " + Ссылка.ИНН);

    // Родитель в иерархическом справочнике
    Если ЗначениеЗаполнено(Ссылка.Родитель) Тогда
        Сообщить("Группа: " + Ссылка.Родитель.Наименование);
    КонецЕсли;

    // Предопределённый элемент
    Валюта = Справочники.Валюты.Рубль;
    Сообщить("Валюта по умолчанию: " + Валюта.Наименование);
КонецПроцедуры
```

## Типичные ошибки

- Изменение реквизита через ссылку: `Ссылка.Наименование = "..."` недопустимо, требуется `ПолучитьОбъект()`.
- Поиск по коду при пустом коде возвращает пустую ссылку, а не ошибку.
- `НайтиПоНаименованию` без флага поиска в группах не находит элементы внутри папок.
- Удаление предопределённого элемента или переименование предопределённого реквизита.
- Обращение к реквизитам группы, которых у группы нет (реквизиты заполняются по-разному при иерархии).
