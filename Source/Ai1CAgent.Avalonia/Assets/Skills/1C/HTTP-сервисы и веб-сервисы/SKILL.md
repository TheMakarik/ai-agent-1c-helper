# HTTP-сервисы и веб-сервисы

## Назначение

Скилл описывает публикацию и разработку сервисов на стороне 1С: HTTP-сервисы (REST-подобные) и веб-сервисы (SOAP/WSDL). Помогает настроить шаблоны URL, обработчики методов, ответы и вызывать сервисы из внешних систем.

## Ключевые понятия

- HTTP-сервис — объект метаданных с корневым URL, шаблонами URL и методами.
- Шаблон URL — путь внутри сервиса, может содержать параметры вида `{Ид}`.
- Метод HTTP — `GET`, `POST`, `PUT`, `DELETE`, `PATCH`; обработчик привязан к шаблону и методу.
- Веб-сервис — объект метаданных с операциями и WSDL; обмен описывается XDTO-пакетами.
- XDTO — модель типов для сериализации данных сервисов.
- Публикация — настройка веб-сервера (Apache/IIS) с указанием каталога и адреса публикации базы.

## Как это работает

1. Создаётся HTTP-сервис, задаётся корневой URL (например, `api`).
2. Добавляются шаблоны URL (`/goods/{Артикул}`) и методы с обработчиками.
3. Обработчик получает `HTTPСервисЗапрос` и возвращает `HTTPСервисОтвет` с кодом, заголовками и телом.
4. База публикуется на веб-сервере; сервис доступен по адресу `<публикация>/hs/api/...`.
5. Для веб-сервиса задаются XDTO-пакеты, типы и операции; клиент получает WSDL.

Тело запроса и ответа читается `Запрос.ПолучитьТелоКакСтроку()` / `Запрос.ПолучитьТелоКакДвоичныеДанные()`; ответ задаётся `Ответ.УстановитьТелоИзСтроки(...)` и заголовком `Content-Type`. Аутентификация при публикации — встроенная или Basic; секреты не хранят в коде.

## Пример

```bsl
// Пример: обработчик HTTP-сервиса, метод POST, шаблон /goods/{Артикул}.
Функция ПолучитьТоварPOST(Запрос) Экспорт
    Артикул = Запрос.ПараметрыURL.Артикул;

    Ответ = Новый HTTPСервисОтвет(200);
    Попытка
        Товар = Справочники.Номенклатура.НайтиПоРеквизиту("Артикул", Артикул);
        Если Не ЗначениеЗаполнено(Товар) Тогда
            Ответ.КодСостояния = 404;
            Ответ.УстановитьТелоИзСтроки("Товар не найден");
            Возврат Ответ;
        КонецЕсли;

        Ответ.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
        Ответ.УстановитьТелоИзСтроки(
            "{""articul"":""" + Артикул + """,""name"":""" + Товар.Наименование + """}");
    Исключение
        Ответ.КодСостояния = 500;
        Ответ.УстановитьТелоИзСтроки(ОписаниеОшибки());
    КонецПопытки;
    Возврат Ответ;
КонецФункции
```

Вызов извне (пример):

```bsl
// Пример: обращение к HTTP-сервису через HTTPСоединение из другого приложения 1С.
Соединение = Новый HTTPСоединение("server", 80, "user", "password");
Запрос = Новый HTTPЗапрос("/api/hs/goods/001");
Ответ = Соединение.ВызватьHTTPМетод("GET", Запрос);
```

## Типичные ошибки

- База не опубликована или указан неверный адрес публикации.
- Неверный HTTP-метод или шаблон URL: возвращается 404/405.
- Обработчик возвращает `Неопределено` вместо `HTTPСервисОтвет`.
- Отсутствует или неверен заголовок `Content-Type`, кодировка ломает кириллицу.
- Исключения обрабатываются отправкой тела с кодом 200 вместо 4xx/5xx.
- Пароли и токены зашиты в код обработчика или в примеры.
- Не заданы XDTO-типы для веб-сервиса: некорректный WSDL и ошибки десериализации.
- Долгие операции в синхронном обработчике без таймаутов и логирования.
