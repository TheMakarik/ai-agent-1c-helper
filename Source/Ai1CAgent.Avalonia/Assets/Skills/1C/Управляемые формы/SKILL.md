# Управляемые формы

## Назначение

Раздел описывает управляемые формы в 1С: их структуру, реквизиты, назначение и различия основных форм объектов, форм списков и форм выбора. Скилл применяется при разработке форм документов, справочников, обработок и отчётов.

## Ключевые понятия

- **Управляемая форма** — форма, отрисовываемая платформой на клиенте и сервере.
- **Реквизит формы** — данные формы, связывающие интерфейс и объект.
- **Основная форма** — форма открытия объекта по умолчанию.
- **Форма списка** — форма динамического списка записей.
- **Форма выбора** — форма выбора значения из списка.
- **Элементы формы** — визуальные компоненты, привязанные к реквизитам.
- **Команды формы** — действия, доступные из интерфейса и командной панели.

## Как это работает

Форма описывается декларативно в редакторе и работает и на клиенте, и на сервере. Данные формы хранятся в реквизитах: основной реквизит с типом объекта связывает форму с объектом метаданных. События разделены на клиентские и серверные обработчики с помощью директив компиляции.

Форма списка строится на основе динамического списка реквизита. Форма выбора открывается при интерактивном выборе значения. Основную форму можно задать в свойствах объекта метаданных и открыть командой или процедурой `ОткрытьФорму`.

## Пример

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    
    // Основной реквизит формы типа ДокументОбъект
    Если Объект.Ссылка.Пустая() Тогда
        Объект.Дата = ТекущаяДатаСеанса();
        Объект.Организация = ПолучитьОрганизациюПоУмолчанию();
    КонецЕсли;
    
    // Настройка формы списка: колонки и условное оформление
    Если Параметры.Свойство("Отбор") Тогда
        Элементы.Список.Отбор.Элементы.Очистить();
    КонецЕсли;
    
КонецПроцедуры

&НаКлиенте
Процедура ПоказатьВыборОрганизации(Команда)
    
    ПараметрыОткрытия = Новый Структура("ЗакрыватьПриВыборе", Истина);
    ОткрытьФорму("Справочник.Организации.ФормаВыбора", ПараметрыОткрытия,
        ЭтотОбъект, ЭтотОбъект, ,
        Новый ОписаниеОповещения("ПослеВыбора", ЭтотОбъект, "Организация"));
    
КонецПроцедуры

&НаСервере
Функция ПолучитьОрганизациюПоУмолчанию()
    Возврат Справочники.Организации.ОрганизацияПоУмолчанию();
КонецФункции
```

## Типичные ошибки

- Обращение к клиентскому элементу из серверного кода без директивы.
- Использование основной формы там, где нужна форма выбора, и наоборот.
- Смешение логики объекта и данных формы без учёта основного реквизита.
- Ошибки доступа к реквизитам на клиенте, где их значение не передаётся.
- Изменение реквизитов объекта из клиентского обработчика напрямую.
