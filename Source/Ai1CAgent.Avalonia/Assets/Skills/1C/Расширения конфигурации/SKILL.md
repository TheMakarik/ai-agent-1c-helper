# Расширения конфигурации

## Назначение

Расширение — это механизм платформы 1С, позволяющий дорабатывать типовую, отраслевую или собственную конфигурацию, не изменяя её саму. Расширение подключается к информационной базе, «наслаивается» на основную конфигурацию и дополняет или переопределяет её поведение.

Скилл помогает выбрать способ доработки и корректно применить аннотации расширения при изменении модулей.

## Ключевые понятия

- Основная конфигурация — конфигурация, которая находится на поддержке у поставщика.
- Расширение — отдельная конфигурация, которая хранится и поставляется независимо (файл `.cfe`).
- Заимствование объекта — добавление объекта основной конфигурации в расширение, чтобы изменить его свойства, формы или модули.
- Аннотации расширения: `&ИзменениеИКонтроль`, `&Вместо`, `&Перед`, `&После`.
- `&ИзменениеИКонтроль` — замена метода с сохранением оригинального кода для сравнения; в аргументе указывается имя переопределяемого метода.
- `&Вместо` — полная замена метода без сохранения оригинала для сравнения.
- `&Перед` / `&После` — вызов кода расширения до или после оригинального метода.

## Как это работает

1. В Конфигураторе создаётся расширение (Файл → Новое → Расширение конфигурации), задаётся назначение (какую конфигурацию расширять).
2. Нужный объект заимствуется из основной конфигурации (правая кнопка → Заимствовать).
3. В модулях заимствованного объекта добавляются процедуры и функции с аннотациями расширения.
4. Расширение применяется к базе при обновлении конфигурации; несколько расширений применяются в порядке подключения.
5. Расширение можно включить, отключить или удалить без правки основной конфигурации.

Приоритет: методы с `&Вместо` из более позднего расширения перекрывают предыдущие, поэтому конфликты `&Вместо` между расширениями проектируют заранее. Отличия от изменения типовой: расширение сохраняет возможность обновления через поставщика и обратимо.

## Пример

```bsl
// &ИзменениеИКонтроль: собственная реализация метода целиком,
// при этом оригинальный код сохраняется для сравнения и объединения.
&ИзменениеИКонтроль("ЗаполнитьСкидку")
Процедура Расш_ЗаполнитьСкидку()
    Скидка = Мин(МаксСкидка, Скидка + 5);
КонецПроцедуры

// &Вместо: полная замена метода без сохранения оригинального кода для сравнения.
&Вместо("ЦенаСУчетомСкидки")
Функция Расш_ЦенаСУчетомСкидки(Цена, Скидка)
    Возврат Цена - Скидка;
КонецФункции

// &После: добавление кода к оригинальному методу без его изменения.
&После("ПриЗаписи")
Процедура Расш_ПослеПриЗаписи()
    ОбщегоНазначения.ЗаписатьИсториюДанных(Ссылка);
КонецПроцедуры
```

## Типичные ошибки

- Доработка основной конфигурации вместо расширения: теряется возможность обновления типовой.
- Использование `&Вместо`, когда достаточно `&После` или `&ИзменениеИКонтроль`.
- Конфликт нескольких расширений, заменяющих один и тот же метод через `&Вместо`.
- Попытка заимствовать объект без правильно выбранного назначения расширения.
- Изменение структуры данных через расширение там, где типовая предоставляет настройку.
- Забытая новая версия расширения: в базу применяется старая сборка.
