# Планы видов характеристик

## Назначение

План видов характеристик описывает свойства объектов: перечень характеристик и допустимые типы их значений. Он позволяет во время работы заводить новые свойства без изменения структуры конфигурации. Значения характеристик хранятся отдельно — обычно в регистре сведений с измерениями «объект» и «свойство».

## Ключевые понятия

- Вид характеристики — элемент плана (например, «Цвет», «Размер», «Мощность»).
- Тип значения — набор типов, которые может принимать характеристика (Строка, Число, СправочникСсылка, Булево).
- Дополнительные реквизиты — собственные поля элемента плана (например, единица измерения свойства).
- Справочник-владелец — таблица значений характеристик, привязанная к плану.
- Регистр сведений значений — где фактически лежат значения по паре «объект — свойство».
- Предопределённые элементы — заданные в конфигурации характеристики.

## Как это работает

Разработчик описывает план видов характеристик, задавая тип значения. При вводе нового свойства пользователь создаёт элемент плана и указывает его тип. Значения сохраняются в регистре сведений, где измерение объекта ссылается на элемент плана, а измерение свойства — на элемент плана видов характеристик. Так одна таблица хранит разнородные свойства разных объектов.

При чтении значения проверяют тип через `ТипЗначения` и приводят к нужному представлению. Для поиска по значениям характеристики нужно знать тип, так как регистр хранит значение в общем ресурсе составного типа. Если свойств немного и они не меняются, вместо плана видов характеристик применяют справочник или реквизиты.

## Пример

Создание характеристики и её значения:

```bsl
// Создание нового свойства во время работы
Свойство = ПланыВидовХарактеристик.СвойстваНоменклатуры.СоздатьЭлемент();
Свойство.Наименование = "Материал корпуса";
Свойство.ТипЗначения = Новый ОписаниеТипов("Строка");
Свойство.Записать();

// Запись значения свойства для конкретной номенклатуры
Набор = РегистрыСведений.ЗначенияСвойствНоменклатуры.СоздатьМенеджерЗаписи();
Набор.Номенклатура = СсылкаНаНоменклатуру;
Набор.Свойство = Свойство.Ссылка;
Набор.Значение = "Пластик";
Набор.Записать();
```

Чтение значения и приведение к типу:

```bsl
Отбор = Новый Структура("Номенклатура, Свойство", Номенклатура, Свойство);
Записи = РегистрыСведений.ЗначенияСвойствНоменклатуры.Получить(Отбор);
Для Каждого Запись Из Записи Цикл
    Значение = Запись.Значение;
    Если ТипЗнч(Значение) = Тип("СправочникСсылка.Цвета") Тогда
        Представление = Значение;
    КонецЕсли;
КонецЦикла;
```

## Типичные ошибки

- Хранят значения свойств в реквизитах справочника, хотя свойства добавляются пользователем, — требуется план видов характеристик и регистр.
- Не задают `ТипЗначения` и пытаются записать любое значение — ошибка типа.
- Сравнивают составной ресурс как строку, не приводя тип, — некорректный поиск.
- Создают дубли свойств одинаковых по смыслу — нет контроля уникальности наименования.
- Путают дополнительный реквизит плана (описание свойства) и значение свойства (данные объекта).
- Забывают про регистр сведений и пытаются хранить значения в самом плане.
