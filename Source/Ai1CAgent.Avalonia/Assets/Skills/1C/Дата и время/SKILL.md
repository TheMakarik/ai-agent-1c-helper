# Дата и время

## Назначение

Скилл описывает тип `Дата` в языке 1С: как создавать даты, извлекать компоненты, выполнять арифметику и правильно форматировать значения с учётом часовых поясов.

## Ключевые понятия

- `Дата` хранит дату и время с точностью до секунды.
- Литерал: `'20240115093000'` — формат `ГГГГММДДЧЧММСС`.
- `ТекущаяДата()` — текущее время сервера (локальное).
- `Дата(...)`, `Год`, `Месяц`, `День`, `Час`, `Минута`, `Секунда` — конструктор и компоненты.
- `НачалоДня`, `КонецДня`, `ДобавитьМесяц`, `НачалоМесяца` — операции с датами.
- `ЧасовойПояс()` и `УниверсальноеВремя` — работа с часовыми поясами.

## Как это работает

- Дата и число нельзя складывать напрямую; для сдвига используйте `ДобавитьМесяц` или конструктор `Дата(Год, Месяц, День, Час, Минута, Секунда)`.
- Разница двух дат возвращается в секундах: `Конец - Начало`.
- `ТекущаяДата()` возвращает время сервера без пояса; `ТекущаяДатаСеанса()` — с поясом сеанса.
- При хранении в базе используется дата без часового пояса, если реквизит не настроен иначе.
- Форматирование выполняется функцией `Формат` с маской `ДФ`.

## Пример кода

```bsl
// Возвращает возраст в полных годах на указанную дату
Функция ВозрастНаДату(ДатаРождения, ДатаОтсчёта = Неопределено) Экспорт
    Если ДатаОтсчёта = Неопределено Тогда
        ДатаОтсчёта = ТекущаяДата();
    КонецЕсли;

    Лет = Год(ДатаОтсчёта) - Год(ДатаРождения);
    Если Месяц(ДатаОтсчёта) < Месяц(ДатаРождения) Тогда
        Лет = Лет - 1;
    ИначеЕсли Месяц(ДатаОтсчёта) = Месяц(ДатаРождения)
        И День(ДатаОтсчёта) < День(ДатаРождения) Тогда
        Лет = Лет - 1;
    КонецЕсли;

    Возврат Лет;
КонецФункции

// Демонстрация операций с датами
Процедура ОперацииСДатами()
    Начало = НачалоДня(ТекущаяДата());
    Конец = КонецДня(ТекущаяДата());
    Сообщить("Секунд в сутках: " + (Конец - Начало));

    // Сдвиг на месяц вперёд
    СледующийМесяц = ДобавитьМесяц(Начало, 1);
    Сообщить(Формат(СледующийМесяц, "ДФ='dd.MM.yyyy HH:mm:ss'"));

    // Конструирование даты из компонентов
    Отчётная = Дата(2024, 12, 31, 23, 59, 59);
    Сообщить(Отчётная);

    // Границы периода для запроса
    НачалоМес = НачалоМесяца(ТекущаяДата());
    КонецМес = КонецМесяца(ТекущаяДата());
    Сообщить("Период: " + НачалоМес + " — " + КонецМес);
КонецПроцедуры
```

## Типичные ошибки

- Сложение даты и числа (`Дата + 1`) вместо `ДобавитьМесяц` или расчёта секунд.
- Сравнение дат с учётом времени, когда ожидается сравнение только по дате: применяйте `НачалоДня`.
- Использование `ТекущаяДата()` в условиях, где нужна единая точка времени: кэшируйте значение.
- Путаница `ТекущаяДата()` и `ТекущаяДатаСеанса()` при работе с часовыми поясами.
- Форматирование в строке запроса вместо передачи даты параметром.
