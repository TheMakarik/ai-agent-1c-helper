# Внешние обработки

## Назначение

Скилл описывает внешние обработки и отчёты 1С — отдельные файлы `.epf`/`.erf`, которые подключаются к базе без изменения конфигурации. Они применяются для разовых и служебных задач, выгрузок, печати, обслуживания данных и как дополнительные отчёты и обработки.

## Ключевые понятия

- Внешняя обработка — файл `.epf` с формой, реквизитами и модулями.
- Внешний отчёт — файл `.erf`, аналог отчёта, хранится вне конфигурации.
- Внешняя форма — форма, существующая вне конфигурации и открываемая по требованию.
- Подключение — открытие файла через «Файл → Открыть» или программный запуск.
- Дополнительные отчёты и обработки (БСП) — механизм подключения внешних файлов через справочник конфигурации.
- Вставка в конфигурацию — перенос обработки в дерево метаданных при необходимости тиражирования.

## Как это работает

1. Обработка разрабатывается в Конфигураторе как внешний файл (Файл → Новое → Внешняя обработка).
2. В модуле объекта добавляются экспортные процедуры и функции, в форме — интерфейс запуска.
3. Файл открывается в режиме предприятия и выполняется; данные базы доступны через глобальный контекст.
4. Для системного подключения используется механизм БСП «Дополнительные отчёты и обработки»: файл регистрируется и вызывается по команде.
5. При необходимости внешняя обработка вставляется в конфигурацию и становится её частью.

Ограничения: внешние обработки не могут добавлять собственные объекты метаданных и модули объектов; используется только контекст базы и общие модули конфигурации. Встроить внешнюю обработку можно и программно: создать объект и вызвать его экспортный метод, передав параметры запуска.

Для безопасного запуска обработка должна возвращать результат и не оставлять незафиксированных изменений. Перед подключением файл проверяют на тестовой базе и хранят под контролем версий вместе с описанием назначения.

## Пример

```bsl
// Пример: запуск внешней обработки по файлу через механизм БСП.
Процедура ЗапуститьВнешнююОбработку(ПутьКОбработке) Экспорт
    // ВнешниеОбработки — общий модуль БСП для работы с .epf/.erf.
    Обработка = ВнешниеОбработки.Создать(ПутьКОбработке);
    // Вызов экспортной процедуры, объявленной в модуле объекта обработки.
    Обработка.ВыполнитьОбработку();
КонецПроцедуры
```

## Типичные ошибки

- Ожидание от внешней обработки собственных объектов метаданных и модулей объектов.
- Несовпадение версии платформы: обработка собрана в версии новее базы.
- Отсутствие обработки ошибок внутри обработки: сбой прерывает работу пользователя.
- Жёстко прописанные пути и реквизиты вместо параметров запуска.
- Размещение обработки в общем месте без контроля версий и обновления.
- Использование внешней обработки для регулярных задач вместо регламентного задания конфигурации.
- Запуск обработки без проверки прав пользователя: внешний код обходит интерфейсные ограничения.
- Секреты и пароли, оставленные в коде обработки.
