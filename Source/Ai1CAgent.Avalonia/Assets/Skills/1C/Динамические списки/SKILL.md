# Динамические списки

## Назначение

Раздел описывает динамические списки управляемых форм: настройку, отбор, использование произвольного запроса и параметров. Скилл применяется при построении форм списков справочников, документов и регистров.

## Ключевые понятия

- **Динамический список** — реквизит формы, отображающий данные с сервера.
- **Основная таблица** — источник списка (таблица метаданных).
- **Произвольный запрос** — ручной текст запроса для сложного списка.
- **Отбор** — условие на записи, задаваемое программно или в настройках.
- **Параметр списка** — значение, подставляемое в запрос списка.
- **Настройка списка** — выбранные поля, порядок, группировки.

## Как это работает

Динамический список объявляется как реквизит формы типа `ДинамическийСписок`. Платформа строит запрос по основной таблице и применяет отбор и параметры. При использовании произвольного запроса текст задаётся в свойстве `ТекстЗапроса`, а параметры объявляются и заполняются в `ПриСозданииНаСервере`.

Отбор списка задаётся через `Список.Отбор`. Значения параметров запроса устанавливаются через `Список.Параметры`. При обновлении параметров список автоматически перечитывается.

## Пример

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    
    // Произвольный запрос динамического списка
    Список = РеквизитФормыВЗначение("Список", Тип("ДинамическийСписок"));
    Список.ТекстЗапроса =
        "ВЫБРАТЬ
        |   Товары.Ссылка КАК Ссылка,
        |   Товары.Наименование КАК Наименование,
        |   Товары.Цена КАК Цена
        |ИЗ
        |   Справочник.Товары КАК Товары
        |ГДЕ
        |   Товары.ПометкаУдаления = ЛОЖЬ
        |   И Товары.Цена >= &МинимальнаяЦена";
    ЗначениеВРеквизитФормы(Список, "Список");
    
    // Параметры запроса списка
    Список.Параметры.МинимальнаяЦена = 0;
    
    // Программный отбор
    Отбор = Список.Отбор;
    ЭлементОтбора = Отбор.Элементы.Добавить(Тип("ЭлементОтбора"));
    ЭлементОтбора.ЛевоеЗначение = Новый ПолеКомпоновкиДанных("Наименование");
    ЭлементОтбора.ВидСравнения = ВидСравненияКомпоновкиДанных.Содержит;
    ЭлементОтбора.ПравоеЗначение = "Молоко";
    
КонецПроцедуры

&НаКлиенте
Процедура ПрименитьЦену(Команда)
    ПрименитьЦенуНаСервере();
КонецПроцедуры

&НаСервере
Процедура ПрименитьЦенуНаСервере()
    Список = РеквизитФормыВЗначение("Список", Тип("ДинамическийСписок"));
    Список.Параметры.МинимальнаяЦена = МинимальнаяЦена;
    ЗначениеВРеквизитФормы(Список, "Список");
КонецПроцедуры
```

## Типичные ошибки

- Параметр используется в запросе, но не объявлен в `Список.Параметры`.
- Изменение текста запроса на клиенте вместо серверного кода.
- Отбор задан по полю, отсутствующему в выбранных полях списка.
- Сброс пользовательских настроек при каждом открытии формы.
- Тяжёлый запрос без индексов и отборов, приводящий к долгой загрузке.
