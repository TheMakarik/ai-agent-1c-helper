# Встроенные типы

## Назначение

Скилл знакомит со встроенными типами языка 1С, объясняет разницу между примитивными и ссылочными типами и специальными значениями `Неопределено` и `NULL`.

## Ключевые понятия

- Примитивные типы: `Число`, `Строка`, `Дата`, `Булево`.
- Специальные значения: `Неопределено`, `NULL`.
- Ссылочные типы: `СправочникСсылка`, `ДокументСсылка`, `Ссылка` на объекты метаданных.
- Коллекции: `Массив`, `Структура`, `Соответствие`, `ТаблицаЗначений`.
- Тип значения определяют функциями `ТипЗнч()` и `Тип()`.

## Как это работает

- `Число` — вещественное число с плавающей точкой, разделитель целой и дробной части в литералах — точка.
- `Строка` — текст в двойных кавычках, допускается конкатенация через `+`.
- `Дата` — точка во времени с точностью до секунды; литерал задаётся в одинарных кавычках с составным форматом.
- `Булево` — `Истина` или `Ложь`.
- `Неопределено` — значение по умолчанию для неинициализированных переменных; признак «значение не задано».
- `NULL` — отсутствие значения в базе данных, приходит из запросов; не равно `Неопределено`.
- Ссылка на объект (`СправочникСсылка.Товары` и т. п.) — уникальный идентификатор записи в базе.

## Пример кода

```bsl
// Наглядно показывает разницу примитивных и ссылочных типов
Процедура ДемонстрацияТипов()
    Цена = 199.90;                       // Число
    Наименование = "Ноутбук";            // Строка
    ДатаСоздания = '20240115093000';     // Дата
    Активен = Истина;                    // Булево
    ЗначениеНеЗадано = Неопределено;     // Неопределено

    // Проверка фактического типа значения
    Если ТипЗнч(Цена) = Тип("Число") Тогда
        Сообщить("Цена — это число");
    КонецЕсли;

    // Специальное значение нельзя использовать в арифметике без проверки
    Если ЗначениеНеЗадано = Неопределено Тогда
        Сообщить("Значение ещё не установлено");
    КонецЕсли;

    // Пустая ссылка
    Товар = Справочники.Товары.ПустаяСсылка();
    Если НЕ ЗначениеЗаполнено(Товар) Тогда
        Сообщить("Товар не выбран");
    КонецЕсли;
КонецПроцедуры

// Различает Неопределено и NULL при чтении данных
Функция РазобратьЗначение(Значение)
    Если Значение = NULL Тогда
        Возврат "NULL из запроса";
    ИначеЕсли Значение = Неопределено Тогда
        Возврат "Неопределено";
    Иначе
        Возврат Строка(Значение);
    КонецЕсли;
КонецФункции
```

## Типичные ошибки

- Сравнение `NULL` и `Неопределено` как равных: `NULL = Неопределено` — всегда `Ложь`.
- Арифметика с `Неопределено` или `NULL` без проверки приводит к ошибке или пустому результату.
- Попытка присвоить `NULL` значению примитивного типа в переменной вне запроса.
- Использование `ТипЗнч(Значение) = Тип("СправочникСсылка.Номенклатура")` при разных именах типа — проверяйте имя типа точно.
- Проверка заполненности ссылки сравнением с `NULL` вместо `ПустаяСсылка()` или `ЗначениеЗаполнено()`.
