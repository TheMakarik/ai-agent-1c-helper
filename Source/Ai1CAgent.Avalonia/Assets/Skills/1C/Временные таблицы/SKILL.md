# Временные таблицы

## Назначение

Временные таблицы позволяют сохранить промежуточный результат запроса и использовать его в следующих запросах пакета. Это упрощает сложную логику: разбивает задачу на этапы, повторно использует тяжёлый набор данных и даёт платформе возможность индексировать промежуточные таблицы.

## Ключевые понятия

- `ПОМЕСТИТЬ ИмяТаблицы` — сохранить результат запроса во временную таблицу.
- `УНИЧТОЖИТЬ` — удалить временную таблицу, если она больше не нужна.
- `ИНДЕКСИРОВАТЬ ПО` — построить индекс по полям во временной таблице.
- Пакет запросов — несколько запросов, разделённых `;`, выполняются последовательно.
- `ВЫБРАТЬ ... ИЗ ИмяТаблицы` в следующем запросе пакета — обращение к промежуточной таблице.
- Параметр `МенеджерВременныхТаблиц` — контейнер, где живут таблицы пакета.
- Менеджер временных таблиц создаётся в коде: `Новый МенеджерВременныхТаблиц`.

## Как это работает

Запрос с `ПОМЕСТИТЬ` сначала материализует набор строк во временную таблицу, а следующий запрос пакета читает её. Все запросы одного пакета выполняются в одном вызове `ВыполнитьПакет()` и не могут существовать без менеджера временных таблиц. После выполнения таблицы освобождаются вместе с менеджером.

Индексы на временной таблице строят после её заполнения, если по этим полям идут соединения или отборы дальше по пакету. Разбиение на этапы особенно полезно, когда нужно применить агрегат, а затем соединить его с другой таблицей, или когда один и тот же набор используется несколько раз.

## Пример

Пакетный запрос с временной таблицей и индексом:

```bsl
Запрос = Новый Запрос;
Запрос.МенеджерВременныхТаблиц = Новый МенеджерВременныхТаблиц;
Запрос.Текст =
    "ВЫБРАТЬ
    |   Товары.Номенклатура КАК Номенклатура,
    |   СУММА(Товары.Количество) КАК Количество
    |ПОМЕСТИТЬ ПродажиПоТоварам
    |ИЗ
    |   Документ.ПродажаТоваров.Товары КАК Товары
    |ГДЕ
    |   Товары.Ссылка.Дата >= &Начало
    |СГРУППИРОВАТЬ ПО
    |   Товары.Номенклатура
    |ИНДЕКСИРОВАТЬ ПО
    |   Номенклатура
    |;
    |////////////////////////////////////////////////////////////////////////////////
    |ВЫБРАТЬ
    |   Продажи.Номенклатура КАК Номенклатура,
    |   Продажи.Количество КАК Продано,
    |   ЕСТЬNULL(Остатки.КоличествоОстаток, 0) КАК Остаток
    |ИЗ
    |   ПродажиПоТоварам КАК Продажи
    |   ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки(
    |       &Момент, Склад = &Склад) КАК Остатки
    |       ПО Продажи.Номенклатура = Остатки.Номенклатура
    |УНИЧТОЖИТЬ ПродажиПоТоварам";
Запрос.УстановитьПараметр("Начало", НачалоМесяца(ТекущаяДата()));
Запрос.УстановитьПараметр("Момент", ТекущаяДата());
Запрос.УстановитьПараметр("Склад", Склад);
Результат = Запрос.ВыполнитьПакет();
```

## Типичные ошибки

- Запрос с `ПОМЕСТИТЬ` запускают через `Выполнить()` без менеджера временных таблиц — ошибка.
- Индекс строят по полям, которых нет в выборке временной таблицы.
- Обращаются к временной таблице в отдельном запросе, вне пакета, — она уже уничтожена.
- Дублируют имена временных таблиц в одном пакете без `УНИЧТОЖИТЬ`.
- Создают временную таблицу ради одной простой операции — лишний этап.
- Ожидают, что `ВыполнитьПакет()` вернёт один результат: он возвращает массив результатов по числу запросов.
