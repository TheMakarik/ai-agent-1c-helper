# Команды и элементы формы

## Назначение

Раздел описывает команды управляемой формы, элементы интерфейса (кнопки, группы, поля), привязки элементов к реквизитам и условное оформление. Скилл применяется при построении интерфейса форм и организации действий пользователя.

## Ключевые понятия

- **Команда** — именованное действие формы с обработчиком действия.
- **Кнопка** — элемент, вызывающий команду.
- **Группа** — контейнер для компоновки элементов, в том числе командная панель.
- **Привязка** — связь элемента с реквизитом или путём к данным.
- **Условное оформление** — правила изменения вида элементов по условию.
- **Доступность** — программное управление возможностью выполнить команду.

## Как это работает

Команды объявляются в форме или в объекте метаданных. У команды есть обработчик действия, а у кнопки — свойство команды. Командные панели формируются автоматически по стандартным командам и дополняются пользовательскими. Элементы привязываются к реквизитам формы через путь к данным; вложенные реквизиты и табличные части доступны по точечному пути.

Доступность и видимость элементов управляются программно в `ПриСозданииНаСервере` через коллекции `Элементы` и `Команды`. Условное оформление задаётся в свойствах формы и не требует кода.

## Пример

```bsl
&НаСервере
Процедура НастроитьКнопкиНаСервере()
    
    // Управление доступностью команд по правам
    ПроведениеДоступно = ПравоДоступа("Проведение", Метаданные.Документы.РеализацияТоваров);
    Элементы.ПровестиИЗакрыть.ТолькоПросмотр = НЕ ПроведениеДоступно;
    Элементы.СписокТовары.ТолькоПросмотр = НЕ ПроведениеДоступно;
    
    // Скрытие группы для новых объектов
    Элементы.ГруппаОснование.Видимость = ЗначениеЗаполнено(Объект.Основание);
    
КонецПроцедуры

&НаКлиенте
Процедура ЗаполнитьПоОснованию(Команда)
    
    Если НЕ ЗначениеЗаполнено(Объект.Основание) Тогда
        ПоказатьПредупреждение(, "Не указано основание");
        Возврат;
    КонецЕсли;
    
    ЗаполнитьНаСервере(Объект.Основание);
    УстановитьДоступностьЭлементовНаСервере();
    
КонецПроцедуры

&НаСервереБезКонтекста
Процедура УстановитьДоступностьЭлементовНаСервере()
    // Перевычисление доступности после заполнения
КонецПроцедуры
```

## Типичные ошибки

- Кнопка создана без привязки к команде и ничего не выполняет.
- Обработчик команды объявлен на сервере, хотя вызывается клиентской кнопкой без вызова.
- Программное изменение видимости элемента, перекрытое условным оформлением.
- Привязка элемента к пути, которого нет в реквизитах формы.
- Изменение доступности на клиенте вместо серверного вызова.
