# Язык запросов

## Назначение

Язык запросов 1С позволяет выбирать данные из таблиц конфигурации и базы: справочников, документов, регистров, табличных частей. Запрос возвращает таблицу значений и выполняется на стороне сервера, что быстрее поштучного обхода объектов. Запросы — основной способ получения данных для отчётов и обработок.

## Ключевые понятия

- `ВЫБРАТЬ` — список выбираемых полей с псевдонимами через `КАК`.
- `ИЗ` — источник данных; таблица метаданных или вложенный запрос.
- `ГДЕ` — отбор строк до группировки; в него попадают только доступные поля.
- `УПОРЯДОЧИТЬ ПО` — сортировка результата, `ВОЗР`/`УБЫВ`.
- Параметры `&Имя` — значения, передаваемые из кода через `ПараметрЗапроса`.
- Псевдонимы — имена полей результата; на них ссылаются внешние запросы и `ИТОГИ`.
- `ССЫЛКА` — таблица-ссылка на объект без табличных частей (например, `Справочник.Номенклатура`).
- `КАК` — обязателен при обращении к виртуальным таблицам и подзапросам.

## Как это работает

Запрос описывается как текст и выполняется методом `Выполнить()` объекта `Запрос`. Результат — `РезультатЗапроса`, из которого выбирают выборку (`Выбрать()`) или загружают в таблицу значений (`Выгрузить()`). Параметры задаются до выполнения: `Запрос.УстановитьПараметр("Имя", Значение)`.

Сечения: `ГДЕ` фильтрует строки до группировки, `СГРУППИРОВАТЬ ПО` объединяет, `ИМЕЮЩИЕ` фильтрует после. Обязательный порядок предложений: `ВЫБРАТЬ ... ИЗ ... ГДЕ ... СГРУППИРОВАТЬ ПО ... ИМЕЮЩИЕ ... УПОРЯДОЧИТЬ ПО ...`. Все неагрегатные поля выборки должны входить в группировку.

## Пример

Выборка документов с отбором и сортировкой:

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
    "ВЫБРАТЬ
    |   Продажи.Ссылка КАК Документ,
    |   Продажи.Дата КАК Дата,
    |   Продажи.СуммаДокумента КАК Сумма
    |ИЗ
    |   Документ.ПродажаТоваров КАК Продажи
    |ГДЕ
    |   Продажи.Дата >= &НачалоПериода
    |   И Продажи.Проведен
    |УПОРЯДОЧИТЬ ПО
    |   Продажи.Дата УБЫВ";
Запрос.УстановитьПараметр("НачалоПериода", НачалоМесяца(ТекущаяДата()));

Результат = Запрос.Выполнить();
Выборка = Результат.Выбрать();
Пока Выборка.Следующий() Цикл
    Сообщить(Выборка.Документ.Дата + " " + Выборка.Сумма);
КонецЦикла;
```

Запрос с соединением и агрегатом:

```bsl
ВЫБРАТЬ
    Номенклатура.Наименование КАК Наименование,
    СУММА(Реализация.Количество) КАК Продано
ИЗ
    Справочник.Номенклатура КАК Номенклатура
    ЛЕВОЕ СОЕДИНЕНИЕ Документ.Реализация.Товары КАК Реализация
        ПО Номенклатура.Ссылка = Реализация.Номенклатура
СГРУППИРОВАТЬ ПО
    Номенклатура.Наименование
УПОРЯДОЧИТЬ ПО
    Продано УБЫВ
```

## Типичные ошибки

- Поле выборки не входит в `СГРУППИРОВАТЬ ПО` — ошибка «Поле не является агрегатным».
- Используют `ГДЕ` для условия по агрегату — нужно `ИМЕЮЩИЕ`.
- Не задают псевдоним виртуальной таблицы после `КАК` — ошибка синтаксиса.
- Вставляют значения прямо в текст запроса вместо параметров — риск ошибок и инъекции.
- Обходят объекты в цикле по ссылкам вместо запроса — низкая производительность.
- Путают `ССЫЛКА` и таблицу объекта, ожидая реквизиты у первой.
- Отбор по дате без учёта времени: `Дата = &Дата` не находит записи внутри суток.
