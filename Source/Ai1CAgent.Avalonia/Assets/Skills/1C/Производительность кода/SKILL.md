# Производительность кода

## Назначение

Скилл описывает типовые причины медленной работы кода и запросов 1С, способы их устранения и методы измерений. Помогает заменить дорогие операции на пакетные, использовать кэширование и правильно настраивать индексы.

## Ключевые понятия

- Запрос в цикле — выполнение запроса отдельно для каждой строки коллекции.
- Вызов сервера в цикле — метод с директивой `&НаСервере` внутри клиентского цикла.
- Пакетная обработка — один запрос или запись на весь массив данных.
- Кэширование — повторное использование ранее вычисленных значений или объектов.
- Индекс — настройка метаданных, ускоряющая отбор и соединение по полю.
- План запроса — способ оценить стоимость запроса и наличие сканирования таблиц.

## Как это работает

1. Определяется узкое место: замеряется время участка и анализируются запросы.
2. Дорогие операции (запросы, обращения к серверу, чтение по одному) объединяются в пакет.
3. Чтение данных выполняется одним запросом с отбором по массиву значений.
4. Результаты, которые не меняются в пределах операции, кэшируются.
5. При частых отборах и соединениях по полю включают индексирование в метаданных.

Правила: не выполнять запрос внутри цикла; получать реквизиты объектов набором, а не через точку в цикле; не соединять большие таблицы без индексов и отборов; не применять функции к индексируемым полям в условии (ломает индекс).

## Пример

```bsl
// Плохо: запрос в цикле по каждому элементу массива.
Для Каждого Ссылка Из МассивТоваров Цикл
    Запрос = Новый Запрос("ВЫБРАТЬ Цена ИЗ Справочник.Номенклатура ГДЕ Ссылка = &Ссылка");
    Запрос.УстановитьПараметр("Ссылка", Ссылка);
    Выборка = Запрос.Выполнить().Выбрать();
    // ...
КонецЦикла;

// Хорошо: один запрос по массиву значений.
Запрос = Новый Запрос;
Запрос.Текст =
    "ВЫБРАТЬ
    |   Номенклатура.Ссылка КАК Ссылка,
    |   Номенклатура.Цена КАК Цена
    |ИЗ
    |   Справочник.Номенклатура КАК Номенклатура
    |ГДЕ
    |   Номенклатура.Ссылка В (&МассивТоваров)";
Запрос.УстановитьПараметр("МассивТоваров", МассивТоваров);
Выборка = Запрос.Выполнить().Выбрать();

// Кэш на время операции: чтение общего значения один раз.
Если КэшНастройки = Неопределено Тогда
    КэшНастройки = ОбщегоНазначения.ЗначениеНастройки("Режим");
КонецЕсли;
```

## Типичные ошибки

- Запрос, выполняемый в цикле на каждую строку.
- Обращение к реквизитам объекта «через точку» в цикле: скрытые запросы к базе.
- Чтение объектов по одному вместо набора/запроса целиком.
- Соединение или отбор по неиндексированному полю на большой таблице.
- Функции над полем в условии (`ГОД(Дата) = ...`) мешают использовать индекс.
- Обращение к итогам без отбора или с избыточным периодом.
- Кэширование, живущее дольше операции: возврат устаревших данных.
- Преждевременная оптимизация без замера длительности.
