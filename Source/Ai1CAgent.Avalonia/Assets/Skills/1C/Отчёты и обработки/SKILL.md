# Отчёты и обработки

## Назначение

Раздел описывает объекты метаданных «Отчёт» и «Обработка»: зачем они нужны, какие содержат формы, макеты и реквизиты, как программно работать с основными и вспомогательными формами. Скилл применяется при создании нового отчёта или обработки и при их подключении к интерфейсу.

## Ключевые понятия

- **Отчёт** — объект метаданных для получения и печати данных, обычно на базе СКД.
- **Обработка** — объект метаданных для выполнения разовых действий и сервисных операций.
- **Основная форма** — форма, открываемая по команде запуска объекта.
- **Форма настроек** — форма для ввода параметров отчёта перед формированием.
- **Макет** — шаблон вывода: табличный документ, текст, СКД, геометрическая схема.
- **Реквизиты объекта** — данные, объявленные на уровне метаданных, доступные формам.

## Как это работает

Отчёт или обработка — это самостоятельный объект метаданных, который имеет собственные формы и макеты. Форма отчёта обычно строится на поле табличного документа и использует механизм СКД. Форма обработки чаще содержит реквизиты для ввода и команды для действий.

Программное открытие выполняется процедурами `ОткрытьФорму` и `ОткрытьФормуМодально` (модальный вызов ограничен и не рекомендуется). Доступ к макету — через `ПолучитьМакет("ИмяМакета")`. Реквизиты объекта доступны через `ЭтотОбъект` и `РеквизитФормыВЗначение`.

## Пример

```bsl
// Открытие отчёта с передачей параметра и запуск формирования
&НаКлиенте
Процедура ОткрытьОтчёт(Команда)
    
    ПараметрыОткрытия = Новый Структура;
    ПараметрыОткрытия.Вставить("Организация", Элементы.Организация.Значение);
    
    Форма = ОткрытьФорму("Отчёт.АнализПродаж.Форма",
        ПараметрыОткрытия,
        ,
        ,
        ,
        ,
        Новый ОписаниеОповещения("ПослеЗакрытияОтчёта", ЭтотОбъект));
    
КонецПроцедуры

&НаСервере
Функция ПолучитьМакетЗаголовка()
    
    ТабличныйДокумент = Новый ТабличныйДокумент;
    Область = ПолучитьМакет("МакетЗаголовка").ПолучитьОбласть("Заголовок");
    ТабличныйДокумент.Вывести(Область);
    
    Возврат ТабличныйДокумент;
    
КонецФункции

&НаСервереБезКонтекста
Функция СформироватьОтчёт(ПараметрыОтчёта)
    
    ОтчётОбъект = Отчёты.АнализПродаж.Создать();
    КомпоновщикНастроек = ОтчётОбъект.СхемаКомпоновкиДанных.НастройкиПоУмолчанию;
    
    Возврат ОтчётОбъект;
    
КонецФункции
```

## Типичные ошибки

- Попытка открыть модальную форму в веб-клиенте или в обработчике без оповещения.
- Обращение к реквизитам объекта напрямую из клиентского кода.
- Передача в параметры открытия структуры с полями, которых нет в форме.
- Вызов `ПолучитьМакет` для макета, не объявленного в объекте.
- Формирование отчёта в `ПриОткрытии` без проверки обязательных параметров.
