# Регистры сведений

## Назначение

Скилл описывает объект метаданных «Регистр сведений»: хранение многомерных данных, измерения, ресурсы и реквизиты, периодичность и подчинение регистратору.

## Ключевые понятия

- Измерения — разрезы хранения, входят в ключ записи.
- Ресурсы — числовые или иные значения, хранимые в разрезе измерений.
- Реквизиты — дополнительные (неключевые) поля записи.
- Периодичность: непериодический, по дню, по месяцу, по секунде и др.
- Независимый регистр — записи создаются напрямую, подчинённый — только регистратором.
- Менеджер записи: `РегистрыСведений.Имя.СоздатьМенеджерЗаписи()`.

## Как это работает

- Ключ записи — совокупность измерений (и период для периодического регистра).
- Для независимого регистра запись выполняют через менеджер записи с установленными измерениями и `Записать()`.
- У периодического регистра есть поле `Период` — момент действия значения.
- Чтение выполняют запросом с отбором по измерениям или через `Получить()`.
- Подчинённый регистр заполняется движениями при проведении документа-регистратора.

## Пример кода

```bsl
// Записывает периодическую цену номенклатуры на дату
Процедура УстановитьЦену(Номенклатура, Дата, Цена) Экспорт
    Если НЕ ЗначениеЗаполнено(Номенклатура) Тогда
        ВызватьИсключение "Не указана номенклатура";
    КонецЕсли;

    МенеджерЗаписи = РегистрыСведений.ЦеныНоменклатуры.СоздатьМенеджерЗаписи();
    МенеджерЗаписи.Период = Дата;
    МенеджерЗаписи.Номенклатура = Номенклатура;
    МенеджерЗаписи.Цена = Цена;
    МенеджерЗаписи.Записать();
КонецПроцедуры

// Возвращает действующую цену на дату через срез последних
Функция ДействующаяЦена(Номенклатура, Дата) Экспорт
    Запрос = Новый Запрос;
    Запрос.Текст =
        "ВЫБРАТЬ ПЕРВЫЕ 1
        |    Цены.Цена
        |ИЗ РегистрСведений.ЦеныНоменклатуры КАК Цены
        |ГДЕ Цены.Номенклатура = &Номенклатура
        |    И Цены.Период <= &Дата
        |УПОРЯДОЧИТЬ ПО Цены.Период УБЫВ";
    Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
    Запрос.УстановитьПараметр("Дата", Дата);

    Выборка = Запрос.Выполнить().Выбрать();
    Если Выборка.Следующий() Тогда
        Возврат Выборка.Цена;
    КонецЕсли;
    Возврат 0;
КонецФункции
```

## Типичные ошибки

- Запись в подчинённый регистр напрямую вместо формирования движений документом.
- Незаполненное измерение в менеджере записи приводит к ошибке при `Записать()`.
- Отсутствие учёта периодичности: чтение цены без отбора по периоду даёт устаревшее значение.
- Дублирование ключа записи: повторная запись перетирает предыдущее значение.
- Использование ресурса в отборе как измерения — ресурсы не индексируются как ключ.
