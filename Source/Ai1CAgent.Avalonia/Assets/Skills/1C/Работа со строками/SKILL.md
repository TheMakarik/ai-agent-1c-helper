# Работа со строками

## Назначение

Скилл описывает функции встроенного языка 1С для обработки строк: разбор, поиск, замену, изменение регистра, сравнение и форматирование значений.

## Ключевые понятия

- `СтрДлина`, `Сред`, `Лев`, `Прав` — работа с длиной и подстроками.
- `СтрНайти`, `СтрЗаменить`, `СтрРазделить`, `СтрСоединить` — поиск, замена и разбор.
- `ВРег`, `НРег`, `ТРег` — приведение регистра.
- `СокрЛ`, `СокрП`, `СокрЛП` — удаление пробелов.
- `Формат` — форматирование значений по маске.
- `СтрШаблон` и `СтрСравнить` — шаблоны и сравнение строк.

## Как это работает

- Индексация подстрок в `Сред` начинается с единицы.
- `СтрНайти` возвращает позицию первого вхождения (с единицы) или 0, если не найдено.
- `СтрЗаменить` заменяет все вхождения, а не только первое.
- `СтрРазделить` возвращает массив, `СтрСоединить` собирает строку из массива.
- Маски `Формат`: `ЧЦ`, `ЧРД`, `ДФ`, `Л`, `Н`, например `Формат(1234.5, "ЧЦ=10; ЧДЦ=2")`.

## Пример кода

```bsl
// Разбирает ФИО, найденное в одной строке, на отдельные части
Функция РазобратьФИО(ПолноеИмя) Экспорт
    Части = СтрРазделить(СокрЛП(ПолноеИмя), " ");

    Если Части.Количество() < 3 Тогда
        ВызватьИсключение "Ожидается три части: фамилия имя отчество";
    КонецЕсли;

    Результат = Новый Структура("Фамилия, Имя, Отчество");
    Результат.Фамилия = Части[0];
    Результат.Имя = Части[1];
    Результат.Отчество = Части[2];
    Возврат Результат;
КонецФункции

// Демонстрация поиска, замены и форматирования
Процедура ОбработатьСтроку(Текст)
    // Приведение к верхнему регистру
    Верхний = ВРег(Текст);
    Сообщить(Верхний);

    // Поиск подстроки (позиция с единицы, 0 — не найдено)
    Позиция = СтрНайти(Текст, "заказ");
    Если Позиция > 0 Тогда
        Сообщить("Слово найдено в позиции " + Позиция);
    КонецЕсли;

    // Замена всех вхождений
    Исправлено = СтрЗаменить(Текст, "заказ", "Заказ");

    // Форматирование числа и даты
    Сумма = 12345.678;
    Сообщить(Формат(Сумма, "ЧЦ=12; ЧДЦ=2; ЧН="));
    Сообщить(Формат(ТекущаяДата(), "ДФ='dd.MM.yyyy'"));

    // Шаблон подстановки значений
    Сообщение = СтрШаблон("Товар %1 стоит %2 руб.", "Хлеб", 45);
    Сообщить(Сообщение);
КонецПроцедуры
```

## Типичные ошибки

- Ожидание нулевого индекса: в `Сред`, `Лев`, `СтрНайти` отсчёт начинается с единицы.
- `СтрЗаменить` в цикле без учёта рекурсивной замены.
- Сравнение строк через `=` без учёта регистра: используйте `СтрСравнить` или `НРег`.
- `Формат` с маской для числа, применённый к строке, возвращает исходное значение.
- Конкатенация `+` с числом без `Строка()` даёт неожиданный результат для дат.
