# Коллекции значений

## Назначение

Скилл описывает встроенные коллекции языка 1С и помогает выбрать подходящую структуру для хранения и обработки наборов данных.

## Ключевые понятия

- `Массив` — упорядоченный список значений с доступом по индексу (с нуля).
- `Структура` — именованные поля, доступ по имени, порядок фиксирован.
- `Соответствие` — пары «ключ — значение» с быстрым поиском по ключу.
- `СписокЗначений` — список значений для интерфейсов, с пометкой, картинкой и представлением.
- `ТаблицаЗначений` — таблица с колонками и строками, аналог таблицы данных в памяти.
- Индексация, `Количество()`, `Добавить()`, `Вставить()`, `Удалить()`, `Очистить()`.

## Как это работает

- `Массив` и `СписокЗначений` упорядочены и допускают одинаковые значения.
- `Соответствие` не сохраняет порядок вставки и не допускает дубликатов ключей.
- `Структура` создаётся с фиксированным набором ключей (или пустой с `Новый Структура`).
- `ТаблицаЗначений` хранит колонки (описанные `НоваяКолонка`) и строки (`Добавить`).
- Обход коллекций выполняется через `Для Каждого ... Из ... Цикл`.

## Пример кода

```bsl
// Демонстрирует основные коллекции языка 1С
Процедура РаботаСКоллекциями()
    // Массив: упорядоченный список
    Товары = Новый Массив;
    Товары.Добавить("Молоко");
    Товары.Добавить("Хлеб");
    Сообщить("Всего товаров: " + Товары.Количество());

    // Структура: именованные поля
    Клиент = Новый Структура("Имя, Возраст", "Иванов", 34);
    Сообщить(Клиент.Имя);
    Если Клиент.Свойство("Возраст") Тогда
        Сообщить("Возраст: " + Клиент.Возраст);
    КонецЕсли;

    // Соответствие: ключ — значение
    Цены = Новый Соответствие;
    Цены.Вставить("Молоко", 80);
    Цены.Вставить("Хлеб", 45);
    Для Каждого КлючИЗначение Из Цены Цикл
        Сообщить(КлючИЗначение.Ключ + ": " + КлючИЗначение.Значение);
    КонецЦикла;

    // СписокЗначений: для выбора и интерфейсов
    Список = Новый СписокЗначений;
    Список.Добавить(1, "Первый");
    Список.Добавить(2, "Второй");
    Список[0].Пометка = Истина;

    // ТаблицаЗначений: таблица в памяти
    Таблица = Новый ТаблицаЗначений;
    Таблица.Колонки.Добавить("Товар", НовыйОписаниеТипов("Строка"));
    Таблица.Колонки.Добавить("Количество", НовыйОписаниеТипов("Число"));
    СтрокаТЧ = Таблица.Добавить();
    СтрокаТЧ.Товар = "Молоко";
    СтрокаТЧ.Количество = 10;
КонецПроцедуры
```

## Типичные ошибки

- Обращение к элементу `Массива` по индексу, равному `Количество()` — выход за границы (индексация с нуля).
- Поиск в `Соответствии` по значению вместо ключа — медленно и неверно.
- `Структура.Вставить()` для отсутствующего ключа создаёт новый ключ, тогда как обращение к несуществующему свойству даёт ошибку.
- Изменение `ТаблицыЗначений` во время обхода `Для Каждого` без использования `НайтиСтроки` и копии.
- Ожидание порядка вставки от `Соответствия`.
