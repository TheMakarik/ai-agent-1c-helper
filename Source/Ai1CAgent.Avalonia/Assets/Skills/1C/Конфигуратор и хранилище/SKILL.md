# Конфигуратор и хранилище

## Назначение

Скилл описывает работу с конфигурацией на этапе разработки: выгрузку и загрузку в файлы, коллективную работу через хранилище конфигурации, сравнение и объединение версий, а также поддержку и обновление типовой конфигурации.

## Ключевые понятия

- Выгрузка/загрузка конфигурации — перенос конфигурации в файл `.cf` и обратно.
- Файл `.cf` — конфигурация; `.cfe` — расширение; `.epf`/`.erf` — внешняя обработка/отчёт; `.dt` — выгрузка всей информационной базы.
- Хранилище конфигурации — сервер коллективной разработки; создаётся файловым или клиент-серверным.
- Захват объекта — монопольная блокировка объекта в хранилище для изменения другим разработчиком.
- Помещение — отправка изменённого объекта в хранилище; версия объекта увеличивается.
- Сравнение и объединение — перенос изменений между конфигурацией и хранилищем, между двумя конфигурациями или файлами.
- Поддержка — состояние объектов типовой конфигурации: «на поддержке», «на поддержке с возможностью изменения», «снято с поддержки».

## Как это работает

1. Разработчик подключается к хранилищу (Конфигурация → Хранилище конфигурации → Подключиться).
2. Объект захватывается под себя, изменяется, затем помещается в хранилище.
3. Для остальных разработчиков изменения становятся доступны после «Обновить конфигурацию из хранилища».
4. Сравнение и объединение (Конфигурация → Сравнить, объединить с конфигурацией из файла/хранилища) переносит объекты и показывает конфликты.
5. Обновление типовой: Конфигурация → Поддержка → Обновление конфигурации, с выбором версии поставщика и режима (с сохранением собственных изменений или без).
6. Перед обновлением делается выгрузка `.dt`, а изменённые объекты снимаются/проверяются по правилам поддержки.

## Пример

```bsl
// Пример: выгрузка конфигурации в файл из встроенного языка.
Процедура ВыгрузитьКонфигурациюВФайл(ПутьКПлатформе, ПутьКБазе, ПутьКФайлу,
    Пользователь, Пароль) Экспорт

    Параметры = "DESIGNER /F """ + ПутьКБазе + """"
        + " /DumpConfigToFile """ + ПутьКФайлу + """"
        + " /N """ + Пользователь + """ /P """ + Пароль + """";
    // Истина — дождаться завершения процесса.
    ЗапуститьПриложение(ПутьКПлатформе + " " + Параметры, , Истина);
КонецПроцедуры
```

## Типичные ошибки

- Обновление типовой без предварительной выгрузки `.dt` и без проверки правил поддержки.
- Забытый захват объекта перед изменением при коллективной работе.
- Оставленные захваченными объекты блокируют других разработчиков.
- Загрузка `.cf` поверх базы без учёта изменений в данных и реквизитов.
- Объединение «вслепую» без разбора конфликтов: теряются доработки.
- Путаница режимов сравнения файла, конфигурации и хранилища.
- Хранение пароля администратора в явном виде в скриптах выгрузки.
