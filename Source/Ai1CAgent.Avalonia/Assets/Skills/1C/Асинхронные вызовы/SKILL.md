# Асинхронные вызовы

## Назначение

Раздел описывает асинхронную модель платформы 1С: ключевое слово `Ждать`, асинхронные методы, процедуры `Асинх` и оповещения, а также открытие внешних ссылок. Скилл применяется там, где нельзя блокировать интерфейс в ожидании результата.

## Ключевые понятия

- **Ждать** — приостановка асинхронной процедуры до готовности результата.
- **Асинх** — процедура с ключевым словом `Асинх`, вызываемая без блокировки.
- **ОписаниеОповещения** — объект с процедурой-обработчиком результата.
- **ЖдатьРезультат** — ожидание завершения группы асинхронных операций.
- **ПолучитьБуфер** — результат асинхронного вызова, получаемый через `Ждать`.
- **OpenURL** — открытие гиперссылки или почтового адреса.

## Как это работает

Асинхронная процедура объявляется как `Асинх Процедура Имя()`. Внутри неё вызовы асинхронных методов сопровождаются оператором `Ждать`, который возвращает результат по завершении операции. Если метод не ждать, он продолжит работу параллельно, а результат придёт в процедуру оповещения.

Асинхронные методы возвращают `АсинхронныйБуфер`, который разыменовывается при `Ждать`. Так работают `ПоместитьФайл`, `НачатьПомещениеФайла`, `ОткрытьФорму` с оповещением и другие. Для ожидания нескольких операций используются `НачатьЖдатьВсе` и `ЖдатьРезультат`.

    Описание = Новый ОписаниеОповещения("ПослеВыбораФайла", ЭтотОбъект);
    
    // Асинхронный диалог выбора файла
    НачатьПомещениеФайла(Описание, Истина, , УникальныйИдентификатор);
    
КонецПроцедуры

    Если Результат = Неопределено Тогда
        Возврат;
    КонецЕсли;
    
    ИмяФайла = Результат.ПолноеИмя;
    ДвоичныеДанные = Результат.ДвоичныеДанные;
    ОбработатьФайлНаСервере(ИмяФайла, ДвоичныеДанные);

КонецПроцедуры

КонецПроцедуры

    // Сохранение и разбор файла на сервере

## Типичные ошибки

- Использование `Ждать` в неасинхронной процедуре — ошибка компиляции.
- Вызов `Асинх`-процедуры без обработки ошибок через оповещение.
- Ожидание асинхронного метода без присваивания результата `Ждать`.
- Обращение к форме после её закрытия из процедуры оповещения.
- Блокирующее ожидание там, где нужна параллельная работа.
